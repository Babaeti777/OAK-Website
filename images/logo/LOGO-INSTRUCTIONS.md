# Logo Instructions

## Logo File Received
The OAK Builders LLC logo has been received and should be placed in this directory.

## Logo Details
- **Company Name**: OAK BUILDERS LLC
- **Design**: Features an oak tree symbol inside the "O"
- **Color**: Gold/Bronze (#C5A563 or similar)
- **Style**: Professional, elegant serif font

## File Placement

### For Static Website
Save the logo image as:
- `images/logo/oak-logo.png` (PNG with transparency recommended)
- `images/logo/oak-logo.svg` (SVG for scalability - optional)

### For WordPress Theme
Copy the logo to:
- `wordpress-theme/oakllc-theme/assets/images/oak-logo.png`
- `wordpress-theme/oakllc-theme/assets/images/oak-logo.svg`

## Upload to WordPress
Once the theme is installed:
1. Go to **Appearance → Customize → Site Identity**
2. Click **Select Logo**
3. Upload the logo image
4. WordPress will handle the rest

## Recommended Sizes
- **Main Logo**: 400px × 150px (or similar aspect ratio)
- **Favicon**: 512px × 512px (square crop of the tree icon)
- **Social Media**: 1200px × 630px (for Open Graph)

The logo has been referenced in all theme files and will display once uploaded.
